conda Cheatsheet 中文版

本文是 conda 官方速查表（Cheatsheet）的中文翻译，译自 conda 官方文档上的最新版本（对应 conda 25.3.1 的官方 PDF）。

阅读时把握一个原则：命令和参数保持原样，只把说明译成中文。命令里的占位符含义如下，实际使用时替换成自己的即可：

  • ENVNAME / NEWENVNAME —— 环境名
  • PKGNAME —— 包名
  • CHANNELNAME —— 渠道名

一、快速开始（Quickstart）

建议为每个新项目或新工作流都创建一个新环境。

命令 说明
conda info 验证 conda 安装情况并查看版本
conda update --name base conda 在 base 环境中更新 conda 本身
conda install anaconda 安装最新完整版 Anaconda 发行版
conda create --name ENVNAME 创建一个新环境
conda activate ENVNAME 激活某个环境（安装包前先激活）

二、渠道与包（Channels and Packages）

使用 conda 时，包的依赖关系和平台差异会被自动处理。

命令 说明
conda list 列出已安装的包
conda list --show-channel-urls 列出已安装的包及其来源渠道信息
conda update --all 更新全部包
conda install --channel CHANNELNAME PKGNAME 从指定渠道安装包
conda install CHANNELNAME::PKGNAME 同上，指定渠道的另一种写法
conda install PKGNAME=3.1.4 安装包的指定版本
conda install "PKGNAME>2.5, <3.2" 按 AND 逻辑安装包（版本须同时满足多个条件）
conda install "PKGNAME [version='2.5|3.2']" 按 OR 逻辑安装包（版本满足其中之一即可）
conda uninstall PKGNAME 卸载包
conda config --show-sources 查看渠道配置来源（渠道写在了哪些配置文件里）
conda config --add channels CHANNELNAME 添加渠道

三、使用 conda 环境（Working with Conda Environments)

会话开始时先列出所有环境；带星号（*）的是当前激活的环境。

命令 说明
conda info --envs 列出所有环境及其所在位置
conda list --name ENVNAME --show-channel-urls 列出指定环境中全部包及其来源渠道
conda install --name ENVNAME PKGNAME1 PKGNAME2 向指定环境中安装包
conda uninstall --name ENVNAME PKGNAME 从指定环境中移除包
conda update --all --name ENVNAME 更新指定环境中的全部包

四、环境管理（Environment Management）

指定环境名，可以把命令的作用范围限定在该环境内。

命令 说明
conda create --name ENVNAME python=3.10 创建带指定 Python 版本的环境
conda create --clone ENVNAME --name NEWENV 克隆（复制）一个现有环境
conda rename --name ENVNAME NEWENVNAME 重命名环境
conda remove --name ENVNAME --all 删除指定环境及其中的全部包
conda list --name ENVNAME --revisions 列出该环境的修订版本历史
conda install --name ENVNAME --revision NUMBER 将环境恢复到指定的修订版本
conda remove --name ENVNAME --channel CHANNELNAME PKGNAME 卸载从指定渠道安装的包

五、导出环境（Exporting Environments）

导出文件用环境名来命名，这样环境名就被保留下来了。

命令 说明
conda export --format=environment-yaml 导出为跨平台兼容格式（YAML）
conda export --format=environment-json 导出为跨平台兼容格式（JSON）
conda export --from-history 从环境的创建历史导出，跨平台兼容
conda export --format=explicit 导出为平台、包专属的显式格式（explicit）
conda export --format=requirements 导出为平台、包专属的 requirements 格式（可供 pip 使用）
conda export --file=environment.yaml 根据文件名自动判断导出格式
conda env export > environment.yml 传统的旧式导出方法

六、导入环境（Importing Environments）

导入环境时，conda 会自动处理平台和包的差异。

命令 说明
conda create --file ENV.yml 从 .yml 文件创建环境
conda create --name ENVNAME --file ENV.txt 从 .txt 文件创建环境

七、其他提示（Additional Hints）

命令 说明
conda COMMAND --help 查看任意命令的帮助
conda search PKGNAME --info 查看某个包的详细信息
conda COMMAND ARG --yes 跳过交互确认直接执行（一次装多个包时很有用）
conda install PKGNAME1 PKGNAME2 --yes 同上：安装多个包，不再逐个询问确认
conda clean --all 清理所有无用的缓存文件
conda config --show 查看当前生效的 conda 配置

译注

  1. 翻译来源与版本：译自 conda 官方文档 Cheatsheet 页面最新版，对应 conda 25.3.1 官方 PDF。
  2. 新旧命令：conda env export > environment.yml 是旧式导出命令，新的官方等价写法是 conda export --format=environment-yaml。本表中的新式命令 conda export 与 conda rename 在我本机的 conda 26.7.2 上均可用。
  3. 术语取舍：channel 统一译作「渠道」（也有教程译作「源」）；base environment 保留 base 不译，与命令行实际显示保持一致；revision 译作「修订版本」，作用类似游戏存档，可以把环境回滚到之前某个状态。
